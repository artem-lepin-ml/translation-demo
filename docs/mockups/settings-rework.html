Дизайн-заметки и трейдофы

Решение

sessionStorage, а не localStorage

Admin-токен живёт в sessionStorage — умирает вместе с вкладкой. localStorage пережил бы закрытие браузера и остался бы на публичном/шаренном устройстве. Цена — токен вводится заново в каждой новой вкладке/сессии; это осознанный компромисс в пользу безопасности демо-стенда, а не полноценной auth-системы (её мы сознательно не строим, см. YAGNI в спеке).

Контракт

Новый эндпоинт GET /api/admin/check

Дешёвая (без мутации) проверка токена: с валидным Bearer → 204, без токена — тоже 204 (значит бэкенд не требует admin вообще, локальная разработка), с неверным токеном → 401 → инлайн «Invalid token». Это чище, чем пробовать unlock через реальный PUT /api/criteria/<id> без изменений — не тратит вызов на «настоящую» ручку и не рискует side-эффектом.

Влияние на прод

Прод нужно пересеять после деплоя

Курация реестра (5 живых OpenRouter-моделей вместо экспериментальной pilot-матрицы с мёртвыми vLLM-строками на localhost:8001) — это изменение сида, а не миграция данных. На проде таблица model уже содержит старые записи; после деплоя ветки нужен явный re-seed (drop + reseed model-таблицы), иначе будет смесь старых и новых строк. Документ и критерии судейства эта операция не трогает.

Что остаётся read-only

Prompt preview у критериев не редактируется

В этой итерации промпт оценщика — просмотр (rendered markdown), даже в Admin mode. Редактирование промпта — отдельное решение владельца (см. «Не делаем» в спеке): слишком велик риск случайно сломать судейскую логику через UI без ревью. Показываем это явно на мокапе, чтобы не создавать ложных ожиданий «всё редактируется».

UX модалок

Ошибки — инлайн в модалке, не молчание

Сейчас `void handleAddEvaluator()` без catch — 401 на проде выглядит как «кнопка не работает». Новый паттерн: та же визуальная форма, что и `va-inspector-warning` (красная рамка + текст), рендерится прямо в теле модалки над кнопками Save/Cancel — в состоянии 2 показан пример инлайн-ошибки сервера (конфликт весов оценщиков).

Params-бейдж

«N params» вместо простыни key:value

Таблица Model Registry раньше рендерила все параметры построчно прямо в ячейке — для моделей с 5-7 полями (temperature, top_k, min_p, enable_thinking...) это разрывало таблицу. Теперь — компактный бейдж с числом параметров, разворачивается по клику в том же месте (без модалки, без перехода).
