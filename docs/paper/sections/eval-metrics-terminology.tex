\paragraph{Terminology Recognition}
We evaluate terminology recognition and normalization at the page level, the
granularity the editor-hyperlink gold of \datasetWikipediaName{} supports.
Each candidate model serves as both the extractor and the disambiguation
judge inside an otherwise fixed deterministic pipeline.
$R_{\mathrm{doc}}^{\mathrm{term}}$ is document-level recall: a gold mention
counts as recovered if its entity is predicted anywhere in the same article.
We compute recall on the terminology-filtered reference tier of 7174 of the
7959 human-linked mentions, which drops structural noise and generic lexical
classes a terminology task should not reward (languages and scripts, taxa,
materials, units). $P_{\mathrm{label}}$ is a conservative lower bound on
precision. Because editors link an entity only at its first mention, the
annotation is incomplete, so a prediction absent from the reference is
additionally credited when its surface form exists as a Wikidata label.
Predictions resolved by the deterministic exact-label match are excluded
from this credit to avoid self-confirmation, keeping the value a lower
bound. The title-sitelink fallback of the grounding pipeline is disabled
during evaluation because it reuses the mechanism the gold annotation is
built from. We report Wilson 95\% confidence intervals in brackets.
