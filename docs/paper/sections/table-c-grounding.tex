\caption{Terminology extraction and Wikidata grounding on the Wikipedia corpus
(100 articles, 7959 gold mentions from editor hyperlinks, 3868 unique
entities). Each candidate model serves as both the extractor and the
disambiguation judge in an otherwise fixed deterministic pipeline. A gold
mention counts as recovered under document-level recall ($R_{\mathrm{doc}}$)
if its entity is predicted anywhere in the same article, under
$R_{\mathrm{span}}$ if token spans overlap, and under $R_{\mathrm{strict}}$ if
position, surface, and entity all match. Because the link annotation is
precise but incomplete, precision is reported as a conservative lower bound:
$P_{\mathrm{mention}}$ scores every prediction, $P_{\mathrm{type}}$
deduplicates repeated (surface, entity) pairs, and $P_{\mathrm{label}}$
additionally credits predictions whose surface exists as a Wikidata label.
The title-sitelink fallback is disabled, as it reuses the mechanism the
annotation is built from. Wilson 95\% confidence intervals are given for
$R_{\mathrm{doc}}$. $^{\dagger}$4.1\% of paragraphs were lost to transient
API failures during this run and are declared in the run metadata.}
