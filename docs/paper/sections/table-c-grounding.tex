\caption{Full metric grid for Table~\ref{tab:grounding-results}, on the
Wikipedia corpus (100 articles, 7959 gold mentions from editor hyperlinks,
3868 unique entities), $R_{\mathrm{all}}$/T0 tier, sitelink-clean. Each
candidate model serves as both the extractor and the disambiguation judge in
an otherwise fixed deterministic pipeline. A gold mention counts as
recovered under document-level recall ($R_{\mathrm{doc}}$) if its entity is
predicted anywhere in the same article, under $R_{\mathrm{span}}$ if token
spans overlap, and under $R_{\mathrm{strict}}$ if position, surface, and
entity all match. Because the link annotation is precise but incomplete,
precision is reported as a conservative lower bound: $P_{\mathrm{mention}}$
scores every prediction, $P_{\mathrm{type}}$ deduplicates repeated (surface,
entity) pairs, and $P_{\mathrm{label}}$ additionally credits predictions
whose surface exists as a Wikidata label. The title-sitelink fallback is

95\% confidence intervals are given for $R_{\mathrm{doc}}$. $^{\dagger}$4.1\%
of paragraphs were lost to transient API failures during this run and are
declared in the run metadata. $P_{\mathrm{label}}$ values are the clean,
sitelink-off recomputation with live label checks; since $P_{\mathrm{label}}$
has no gold-tier dependence, the same clean values are used here and in the
main table. The main table (Table~\ref{tab:grounding-results}) selects the two rungs most
relevant to a system-demo audience: $R_{\mathrm{doc}}$ as the most
permissive recall rung, and $P_{\mathrm{label}}$ as the strictest precision
rung. $^{\ddagger}$GPT-5.4 substitutes GPT-5.5 due to sustained provider rate
limits. The run covers 99 of the 100 articles, so its recall figures are a
