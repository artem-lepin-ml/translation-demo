Отчёт о моделях: CloseRouter + Frontier

Живой прогон обоих провайдеров и допил LLM-клиента проекта под CloseRouter. Всё измерено вживую (curl + реальный путь palimpsest.llm.client), ключи не логировались.

Оба ключа живые haiku на provider-9 / auto — чисто твой provider-10 — 502 клиент допилен + провалидирован

Главное. CloseRouter и Frontier доступны по ключам. Базовая модель anthropic/claude-haiku-4.5 работает чисто и дёшево на маршруте provider-9 (и на auto, который сейчас туда и роутит): честные токены, стоимость surfaced, детерминизм при temperature=0. Но указанный тобой provider-10 сейчас отдаёт 502 (мёртв в 3 из 3 проб), поэтому тесты и дефолт я поставил на auto/provider-9 — пин переключается одной env-переменной, как только 10 оживёт. Клиент проекта допилен под CloseRouter (WAF-UA, ретраи 3×1/3/9с, кап параллелизма 4, фикс чтения стоимости) и провалидирован end-to-end через реальный код, не только curl.

▲ Гоча: haiku оборачивает JSON в ```-фенс

Вопреки «no code fences» модель отдаёт ```json\n{…}\n```. Сырой json.loads падает — но парсер проекта уже снимает фенс (strip("\`") + срез json), так что judge разбирается корректно. Проверено через реальный код: результат — валидный dict.

05

Критические находки и гочи

WAF-UA обязателен

дефолтный UA OpenAI SDK → 403 на любом эндпоинте CloseRouter. Без фикса весь наш код падал бы. Зашито в клиент.

provider-10 лежит

твой пин отдаёт 502 (×3). Дефолт поставил auto; вернуть 10 — CLOSEROUTER_PROVIDER=provider-10, когда оживёт.

cost под cost_usd

не cost. Клиент теперь читает оба (OpenRouter=cost, CloseRouter=cost_usd).

Frontier: числится ≠ сервится

qwen3-vl в /models, но chat → 404. Проверять живым вызовом, не списком.

haiku фенсит JSON

парсер проекта справляется, но любой новый judge-путь должен снимать фенс.

Каталог устарел

снапшот 2026-07-02 не совпал с живым (маршруты сместились). Источник истины — живая проба /endpoints + billing-канарейка.
