Твои 5 находок — закрыты и проверены на живых данных

#НаходкаКорень и фикс
1LLM отказалась резолвить «Париж»Судья видел Q90, но принял дату артефакта из музейной подписи («Конец XXIII в. до н.э.») за ограничение на референт. Оговорка в промпте (общая, не спецкейс) → после перегенерации Париж = Q90 Paris, живьёмfixed
2Пустое описание кандидата; QID некликабеленQID — ссылка на Wikidata; без описания рендерится только label (без висячего тире)fixed
3Дубли лемм в трейсеЭто была эскалация prefix→full-text→sitelink без ярлыков (старые трейсы). Двойной фикс: ярлык стратегии на каждой строке + группировка идентичных строк ×N + перегенерация термов дока 10fixed
4Жёлтая плашка «model: LLM · Settings › Grounding»Удалена вместе с акцент-рамкой — осталась только цитата обоснованияfixed
5Wikinews-статьи в кандидатахP31-блоклист (Wikinews article, disambiguation, категории, шаблоны, списки) на уже скачанных claims + дедуп почти-одинаковых кандидатов. После перегенерации: 0 Wikinews в 119 термахfixed

Перегенерация термов дока 10 выполнена с твоего разрешения (бэкап golden снят): 124 → 119 термов, все три стратегии в трейсах, Париж резолвится.

Находки финального e2e — честный разбор

НаходкаРазборСтатус
«HIGH: Reset вернул §1 к неверной ревизии (Ur-Nanshe, 6.9)»Не баг кода: Reset по контракту возвращает seed, а §1 в golden был давно отрефайнен до-изоляционными прогонами (9.7/Uruinimgina) — его seed всегда был черновиком Андрея.
