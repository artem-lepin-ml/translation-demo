4 Критичные находки

HIGH · среда — WAF шлюза (closerouter) в облачной песочнице режет User-Agent библиотеки openai-python: живой перевод и живая переоценка не завершаются В КОНТЕЙНЕРЕ (fail-path и Retry проверены и работают). На сервере с настоящим ключом OpenRouter этой проблемы нет — но живой happy-path перевода до записи видео нужно прогнать там один раз руками/скриптом.
HIGH · процесс — Деплой на 72.56.109.228 из этой сессии невозможен: песочница claude.ai/code выпускает наружу только HTTPS, SSH заблокирован, обход запрещён. Сервер всё ещё крутит старый билд (admin-токен, Cultural Adaptation на твоём скрине — оттуда). Готов deploy/update-server.sh — одна команда с твоей машины.
HIGH · инструменты — Специализированные агенты из .claude/agents/ (fastapi-developer, react-specialist, …) НЕ регистрируются в облачной сессии — dispatch-карта CLAUDE.md в cloud фактически не работает (файлы есть, harness их не поднял). Реализацию вели general-purpose агентами с явной моделью Sonnet. Требует отдельного разбора (вероятно, формат frontmatter).
INFO · данные — Глоссарий: 83/142 уникальных термов честно без grounding (не нашлись детерминированно), 31 — с кандидатами без выбранного QID (нужна LLM-дизамбигуация — отдельный шаг под бюджетом). Стемминг «Тигр/Тигра» — документированная эвристика до настоящей лемматизации в модуле терминологии.
INFO · охват e2e — Не прогнаны в браузере: .md-strip, windows-1251-фолбэк, .docx-извлечение, drag-drop подсветка, полный матрикс upload-pair (13 состояний). Юнитами покрыты; браузерная добивка — короткий отдельный прогон.
INFO · честные ограничения — Статус перевода in-memory (рестарт теряет бейдж, повторный POST дотягивает); best активируется только для оценок после миграции; PR-футер «Generated by Claude Code» дописывает платформа поверх тела (один раз уже вычищен, может вернуться при следующем автообновлении).
