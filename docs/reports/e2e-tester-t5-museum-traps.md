## Decisions & rationale
- **Вердикт FAIL, а не PASS-WITH-FINDINGS:** спека T5 явно определяет PASS-критерии («оба Фивы → разные правильные древние QID», «ни одного false-green») — оба нарушены, причём худшим классом ошибки (false-resolved). Прогон как процедура успешен, продукт — нет.
- **Эталон для Фив(Греция) исправлен на Q11225429 по Wikidata API**, а не взят из манифеста: Q41621 проверен через wbgetentities и оказался Хайфой; расхождение оформлено отдельной находкой, а не молчаливой подменой.
- **Root cause выведен из traceJson, без повторного минимального репро на проде:** `cache_hit:true` + чужой дословный justification однозначны; direct-repro сжёг бы ещё ~40 LLM-вызовов на проде.
- **Paste-путь модалки** (не файл): файловый путь покрыт T1; манифест разрешает оба.
- **Чтение статусов/термов через same-session `fetch` в браузере** — только наблюдение; весь driving (создание, попапы, глоссарий, Evaluate, удаление) сделан через UI.

## Open questions

- Должен ли exact_label-путь получать хотя бы дешёвую контекстную проверку (сейчас 13/13 зелёных приняты без judge; 1 из 13 неверен).
