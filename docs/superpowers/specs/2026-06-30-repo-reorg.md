# Перегруппировка репозитория

Up-link: [docs/pipeline.md](../../pipeline.md) · опирается на: [keep-minimum манифест](2026-06-30-keep-minimum.md) · дата: 2026-06-30

> Только про перегруппировку файлов и веток. Дизайн самого демо обсуждаем в другом чате.

## Зачем

Сейчас работа размазана по трём веткам и трём worktree. Наводим порядок: **одна чистая ветка под демо** и **одна ветка-архив** под всё старое. Полезные куски из старого переносим, остальное складываем в архив, ничего не теряем.

## Сейчас

- `artem` — старый пайплайн перевода + задеплоенный viewer (`dev` уже внутри `artem`).
- `feat/glossary-overnight` — работа по глоссарию/KG.
- `feat/demo-skeleton` — каркас демо + **незакоммиченный** новый UI (на TipTap).
- `main` — общий каркас проекта (CLAUDE.md, configs, data, скелет бэкенда).

## Станет

- **`artem-demo`** — чистая ветка под новое демо: каркас из `main` + новый UI + перенесённые полезные куски.
- **`artem-translation-old`** — одна ветка-архив со всем старым (перевод + глоссарий). Временно: потом переедет на GitHub, сейчас просто чтобы не потерять.

## Что переносим в `artem-demo`

Только проверенное (из [keep-minimum](2026-06-30-keep-minimum.md)):

- `LLMClient` — единая точка доступа к LLM.
- Ядро оценщика (из `scoring.py`) + применение правок (из `correction.py`).
- Промпты v2 (5 критериев) + перевод/коррекция.
- Рантайм глоссария (`schema.py` + `matcher.py`) + `glossary/main.json`.
- `configs/models.yaml` — реестр моделей.
- Одобренный UI (TipTap).

Остальное (старый viewer, build-пайплайн глоссария, CLI-скрипты) → в архив, в `artem-demo` не тащим.

## Структура `artem-demo` (общий вид)

Монорепо: `frontend/` (Vite + React + TipTap) и `backend/` (**FastAPI + SQLite**). Лицензия — **MIT**. К конкретной паре языков не привязываемся — языки произвольные.

## Шаги перегруппировки

1. **Сначала сохранить новый UI** — он сейчас не закоммичен. Делаю бэкап и коммичу в `feat/demo-skeleton` (это единственный риск потери, поэтому первым делом).
2. **Архив старого** — помечаю старые ветки тегами и завожу одну ветку-указатель `artem-translation-old`. Без слияния деревьев (быстро, без конфликтов).
3. **Создаю `artem-demo`** от `feat/demo-skeleton` (там уже каркас + UI).
4. **Переношу полезные куски** копированием файлов + мелкая чистка (инлайн одного приватного импорта в `matcher.py`, правило Git-LFS для `main.json`).
5. Дальше веду разработку демо в отдельном worktree под `artem-demo`.
