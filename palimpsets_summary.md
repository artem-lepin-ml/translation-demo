# Palimpsest — Интеллектуальный перевод исторических текстов

## Краткая смысловая выжимка для LLM-контекста

- **Цель:** перевести 7 томов БСЭ на английский LLM-средствами к 1 июня 2026; опубликовать как академический стандарт и выпустить research-статью о методологии перевода академических текстов LLM.
- **Участники:** Сбер (ИИ/разработка), ИВИ РАН (издание), МГИМО (терминология и вычитка). Внешняя поддержка — МИД РФ, Правительство РФ.
- **Центральная проблема:** качество LLM-перевода — открытая задача (нет эталона, нерелевантные бенчмарки, нет инструментов для оптимального каскада).
- **Метрика:** взвешенный консенсус по 6 критериям — Accuracy (2.0×), Terminology (1.5×), Consistency (1.5×), Fluency (1.0×), Style (1.0×), Cultural (1.0×).
- **Архитектура каскада (3 этапа):**
  1. Черновик — выбирается модель-лидер по Accuracy.
  2. Правка терминов — лидер по Terminology + Consistency.
  3. Полировка — лидер по Fluency + Style + Cultural.
- **Роли моделей** назначаются автоматически по матрице слепых оценок «судья × перевод». Если одна модель доминирует на ≥1.2 балла по всем критериям — каскад схлопывается в одну модель.
- **Результаты теста:** лидер — **Grok 3** (консенсус 4.50/5, идеальная Terminology 5.0). Близко — «Мой перевод» 4.40. Ниже — Gemma 3 4B (3.80), Llama 3.1 8B (3.80). Mistral 7B — провал.
- **Терминология (пример — «лугаль»):** три стратегии (транскрипция / описание / транскрипция+описание), опора на авторитетные англоязычные источники (Crawford, Van De Mieroop).
- **Дорожная карта:** Пилот (тест 3 глав — выполнено → выбор тома → перевод → верификация МГИМО) → Масштабирование (6 томов + глоссарий + подготовка к публикации в ИВИ РАН) → Тиражирование (презентации, документирование кейса).
- **Открытые решения на текущий момент:** одна LLM vs каскад; выбор пилотного тома; фиксация критериев качества после обратной связи от экспертов.
