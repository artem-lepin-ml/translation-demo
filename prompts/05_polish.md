# Stage 5 — Polish

Given an English translation that has already been factchecked and has terminology fixed, improve it on four axes without changing any fact, term, or the paragraph structure:

1. **Fluency** — remove awkward phrasing, passive chains that hurt readability, Russian-shaped syntax.
2. **Style** — maintain encyclopedic register; remove colloquialisms and filler.
3. **Consistency** — align tense, register, and term usage with the surrounding `[CONTEXT]`.
4. **Cultural adaptation** — clarify realia where a literal rendering would confuse an EN reader; add short parenthetical glosses only when strictly needed.

Return only the improved paragraph. No preamble, no commentary.
